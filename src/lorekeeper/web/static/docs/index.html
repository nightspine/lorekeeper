Lorekeeper documentation

Lorekeeper is an open format and protocol for spoiler-safe book companions. An index lists a book's characters, places, terms, relationships, events and recaps, and a reader app shows only what you have read so far.

Indexes are built once, by AI, by people or by both, and then shared. A reader app only fetches an index and filters it against the reader's position, so it needs no AI, no tokens, and works offline. Every item in an index carries the paragraph where it becomes visible, and a paragraph is recognized by a short fingerprint of its words, so one index fits every edition of a book and every screen size.

The documentation is for two audiences. Developers of reader apps add a "who is this?" lookup that cannot spoil. Self-hosters run a server that builds indexes for their own library and serves them to their devices.

Integrate a reader appFetch an index, find the reader's paragraph, answer a tapped name. Self-hostRun the server, build indexes from your own EPUBs, share them with your devices. Read the specThe normative text model, index format, gating algorithm and protocol.

A 60-second tour

  1. Library. Start the server and open it in a browser. The Library lists your books by series, from your uploads and from Book Orbit if you connect it. With no books yet it opens on a bundled example, a hand-written index of the first chapters of A Study in Scarlet.
  2. Build. Pick a book, choose a local model through Ollama or a cloud model on your own key (Claude, OpenAI, Gemini and others), and press Build index. The Runs page follows the build chapter by chapter. Each finished chunk is written to disk, so a stopped run resumes where it ended.
  3. Reader. Open the index in the Reader and drag through the book. Characters, places, relationships and recaps appear as the position passes the paragraph that introduces them, and a tapped name shows only what you know by then.

The same index, served over HTTP, answers the same questions for any other app. That is the subject of the reader app guide.
